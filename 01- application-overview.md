# 1. Application Overview

## What is the application?

Wolt is a food delivery and commerce platform that connects customers with restaurants, stores, and delivery services.

## Users

The assessment considered the functionality available to a normal authenticated user.

## Main capabilities

The application allows users to:

- Browse restaurants and stores
- Search for products and restaurants
- View product and restaurant information
- Add items to a cart
- Place orders
- Manage account information
- Manage addresses
- Make payments
- Track orders

## Assessment approach

The application was assessed by identifying user capabilities and the business objects associated with those capabilities.

For each capability:

**Capability → Business Object → Application Flow → Testing → Findings**
